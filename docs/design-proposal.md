## 1. 设计定位（一句话）

**把 App 做成一块"夜间城市仪表盘"：底子极暗、信息极少、数字极大，
只留一种橙色的光。**

- Apple 提供的是：留白节奏、字号层级、克制的配色、圆角与阴影
- GTA5 提供的是：深色街头感、日落橙、大写字距的小标签、数值化的 HUD

两者其实不冲突：GTA 的 HUD 本身就是极简的——血条、金钱、时间，全都是一行小字 + 数字。

---

## 2. 视觉语言的六个决定

| 决定 | 做法 | 为什么 |
|---|---|---|
| **只用一个强调色** | 日落橙 `#FF6B1A` | GTA 的标志色，且和地图的绿/蓝反差大，户外也醒目 |
| **背景近黑** | `#0B0D10`（不是纯黑） | 纯黑在 OLED 上边缘发灰；略偏蓝的黑更"夜"、更有电影感 |
| **数字极大** | 距离 400px 字号 | 记录页唯一主角是"走了多远"，其它都该让路 |
| **小标签全大写 + 字距** | `NOT RECORDING`、`165 POINTS` | 这是 GTA HUD 的排版签名，成本极低、气质提升最大 |
| **琥珀做次级强调** | 时长用 `#FFC24B` | 一个橙系色族，两档明度，避免多色杂乱 |
| **分割线代替卡片** | 1px `#262B32` 细分隔线 | 卡片盒子会显"工具软件"，细线才是高级感 |

### 完整色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#0B0D10` | 近黑，微蓝 |
| 面板 | `#14171C` | 底部面板、卡片 |
| 分割线 | `#262B32` | 1px |
| 主文字 | `#F5F5F7` | 不是纯白，降低刺眼 |
| 次文字 | `#8A8F98` | 说明、单位 |
| 弱文字 | `#5A6068` | 小标签 |
| 强调 | `#FF6B1A` | 按钮、进度、当前态 |
| 次强调 | `#FFC24B` | 时长等次级数字 |
| 危险 | `#FF453A` | 删除 |

## 3. 逐屏方案

### 3.1 记录页（`design/01-record.png`）

现状问题：一屏只有一个数字，但周围空得没有秩序，按钮是 Material 默认紫色。

改法：

| 元素 | 改法 |
|---|---|
| 顶部 | 左侧橙色小圆点 + `XINGJI`（字距 3px）；右侧 `行程 / 设置 / AI` 用弱文字，不再抢眼 |
| 状态 | `NOT RECORDING` 小标签，全大写字距 5px |
| 主数字 | 距离 400px，单位「米」96px 与数字**基线对齐**，颜色降一级 |
| 计时 | 150px，与主数字左对齐，形成两条左基准线 |
| 三个次指标 | 均速 / 最高 / 点数，一行等宽，标签小、数值中 |
| 主按钮 | 橙色胶囊，高 150px，文字深色（橙底黑字比白字高级） |
| 底部 | 一条**细进度轨**：表示"定位就绪度"，未定位时只有一小段橙色 |

**GTA 元素**：左上角的橙色圆点就是 GTA 的小地图 blip；`NOT RECORDING` 是 HUD 状态行。
**Apple 元素**：全部元素左对齐成一条基准线，右侧大量留白。

### 3.2 行程列表（`design/02-list.png`）

现状问题：四行小字挤在卡片里，一屏只能看四条，抓不到重点。

改法：改成**行式列表**，去掉卡片盒子：

```
11-16 20:03                    5:28      ← 日期弱、时长琥珀色
932 米                                    ← 距离 110px 粗体
165 点 · 3 段 · 1 个停留                    ← meta 弱文字
──────────────────────────────────────   ← 1px 分隔线
```

信息密度从 4 条提升到 6~7 条，扫视时眼睛只追两个东西：**距离**和**时长**。

### 3.3 行程详情（`design/03-detail.png`）

现状问题：底部卡片里塞了统计、meta、滑块、三个按钮，拥挤。

改法：

- 地图占上方 60%，加一层暗色蒙版（`rgba(11,13,16,.45)`），让橙色轨迹跳出来
- 底部面板圆角 44px，**顶部一条 4px 橙色线**——这是 GTA 任务面板的做法
- 四项统计一行等宽，单位缩到 26px
- meta 行改成大写：`165 POINTS  1 GAP  1 STAY  3 SEGMENTS`
- 滑块：轨道 10px，已播放段橙色，白色圆点带阴影
- 操作按钮只留文字：导出 / 分享图 / 删除（红）

## 4. 动效（克制，只做三处）

| 位置 | 动效 |
|---|---|
| 数字变化 | 距离数字用 `animateFloatAsState` 平滑滚动，不做跳动 |
| 页面切换 | 淡入 + 轻微上移（180ms），不做左右滑动 |
| 按钮按下 | 缩放 0.97 + 透明度，GTA 那种"按下去有反馈"的感觉 |

不做：粒子、炫光、3D 翻转。

## 6. 三个需要你拍板的问题

### ① 户外可读性怎么办？

深色界面在正午阳光下对比度会掉。三个选择：

| 方案 | 说明 | 推荐 |
|---|---|---|
| A. 只做深色 | 最简单，但你白天户外记录会看不清 | |
| B. 深色 + 跟随系统浅色 | 系统浅色时自动切白底黑字 | ✅ |
| C. 深色 + 记录页单独"高对比模式" | 记录页永远白底，其它页深色 | |

### ② GTA 味道要多浓？

| 档位 | 内容 | 风险 |
|---|---|---|
| 保守（当前方案） | 深色 + 日落橙 + 大写小标签 | 无 |
| 中等 | 再加：数字用斜体、顶部渐变天空、blip 圆点标记 | 低 |
| 激进 | 再加：伪任务提示条、加载时的 "WASTED" 式转场 | 容易变游戏化、不严肃 |

建议**保守或中等**。

### ③ 字体要不要换？

系统字体（微软雅黑/思源黑体）没有版权风险，但"高级感"差一点。
GTA 用的是 Pricedown（有版权，**不能商用也不能嵌入**）。

可选：引入开源的 condensed 无衬线（如 `Barlow Condensed`、`Oswald`，都是 SIL 开源协议），
只用于大数字和英文标签，中文继续用系统字体。

**代价**：APK 增加约 300KB，多一个字体文件。

## 7. 我不会做的事（避坑）

1. **不使用 GTA 的任何素材**：logo、地图、角色、字体都不碰，只借用"深色 + 橙 + HUD 排版"这种抽象语言。
2. **不改信息架构**：这一版只动视觉，不动功能位置和交互逻辑，避免改完你不会用。
3. **不引入重型 UI 库**：不加第三方设计系统，纯 Compose + 自定义 token。
