# 澎湃 OS（HyperOS）设置说明

> 给第一次用这个 App 的朋友看的。不设置的话，**锁屏后系统会把记录服务杀掉**，
> 轨迹就断了——这不是 App 的问题，是系统省电策略。

按顺序做这五件事，大概 3 分钟。

---

## 1. 允许自启动

**路径**：设置 → 应用设置 → 应用管理 → 行迹 → 自启动 → 打开

**为什么**：HyperOS 默认禁止第三方 App 自启动。不开的话，手机重启后、
或者系统清理后台后，行迹无法自己恢复记录。

---

## 2. 省电策略改为「无限制」

**路径**：设置 → 应用设置 → 应用管理 → 行迹 → 省电策略 → 选「无限制」

**为什么**：默认是「智能省电」，锁屏几分钟后系统会冻结后台进程。
记录服务被冻结 = 那段时间没有轨迹点。选「无限制」后系统不再冻结它。

---

## 3. 锁定后台（最近任务卡片加锁）

**路径**：打开行迹 → 上滑进最近任务 → 长按行迹的卡片 → 点锁头图标

**为什么**：锁定后，「一键清理」不会清掉行迹。不锁的话，
你随手清一下后台，正在记录的行程就断了。

---

## 4. 通知常驻（允许通知 + 锁屏显示）

**路径**：设置 → 应用设置 → 应用管理 → 行迹 → 通知管理
1. 打开「允许通知」
2. 找到「记录中」这个通知渠道，打开「锁屏通知」并设为「显示」

**为什么**：Android 要求带定位的前台服务必须显示通知。
如果通知被关掉，系统会直接杀掉服务——不是 App 想弹通知，是系统规定。

---

## 5. 电池优化白名单

**路径**：设置 → 电池 → 省电与电池 → 应用智能省电 → 行迹 → 无限制
（部分版本在：设置 → 应用设置 → 特殊权限 → 电池优化 → 行迹 → 不优化）

**为什么**：这是系统级的电池优化名单，和第 2 条是两个不同的开关，
两个都要关。只关一个的话，某些场景（比如充电时不限制、拔电后限制）仍会断。

---

## 怎么确认设置生效

1. 打开行迹 → 开始记录
2. 锁屏，把手机放桌上 **10 分钟**
3. 解锁，看行程详情里的「N 个点」

10 分钟正常应该在 100 个点以上（按 2 秒一个点算）。
如果只有个位数或者出现「断点」，说明上面五条有漏的。

---

## 还断的话，按这个顺序排查

| 现象 | 可能原因 |
|---|---|
| 锁屏后完全没有点 | 第 2 或第 5 条没生效 |
| 一开始有点，几分钟后没了 | 第 2 条（智能省电仍在冻结） |
| 清理后台后没了 | 第 3 条（没锁定卡片） |
| 重启手机后没恢复 | 第 1 条（没开自启动） |
| 通知栏没有「记录中」 | 第 4 条（通知被关，系统杀服务） |
